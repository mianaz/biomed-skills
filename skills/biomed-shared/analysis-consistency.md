# Apply analysis consistency

Use when selecting or reusing a computed feature, or reconciling analyses across
figures, Methods, main text and supplement.

Link each feature to one existing definition and computation record. Check its
inputs, algorithm, preprocessing, key parameters, scaling reference and thresholds.
Reuse saved results for the same samples and definition.

When a biological or technical difference requires an adaptation, name it and
record the reason. A changed primary analysis requires corresponding updates to
affected results and text within the task scope. During review or wording-only
work, locate both conflicting uses and identify the needed repair.

For selecting, computing, reproducing or auditing a gene set or signature, read
[gene-set records](gene-set-records.md). General method selection and reuse follow
the shared principles.
