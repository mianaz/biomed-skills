# Shared biomedical principles

Apply these five principles in every task. Read further guidance only for the
decision at hand; reuse guidance already read from the current version.

1. **Follow the task.** Deliver the requested product at the requested scope.
   Reuse the project's accepted choices, sources and working structure.
2. **Preserve scientific meaning.** Let the biological question guide the work.
   Keep facts and sources accurate, and make findings, interpretations and proposed
   work clear. Develop scientific significance where the task calls for it.
3. **Keep related work consistent.** Reuse definitions, methods and results across
   comparable analyses and outputs. Explain consequential adaptations and update
   affected outputs together within scope.
4. **Reuse and adapt first.** Prefer established methods suited to the question,
   validated resources and mature implementations. Build custom work for an
   explicit request or a concrete need that existing resources do not meet.
5. **Keep work proportionate.** Load only relevant references, retain reusable
   sources and check the actual deliverable. Add steps and artifacts when the
   requested outcome needs them.

## Resolve competing instructions

User requirements and confirmed project choices take precedence over suite
defaults. Source evidence governs factual statements. Shared references own common
defaults; the active skill owns its task's procedure and deliverable. Apply a
task-specific exception only under its stated condition, with a brief reason for
a consequential departure. Resolve a remaining material conflict from its source
or ask for the missing decision while completing unaffected work.
