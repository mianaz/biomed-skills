# Research practice sources

Primary references for the research workflows. Apply institutional policies only
within their stated scope.

| Source | Useful contribution |
| --- | --- |
| Yewdell, [How to succeed in science, Part II](https://pmc.ncbi.nlm.nih.gov/articles/PMC2675886/) (2008) | Creative interpretation, cross-field inspiration, small informative experiments and a record of conclusions and next steps |
| Alon, [How To Choose a Good Scientific Problem](https://doi.org/10.1016/j.molcel.2009.09.013) (2009); [university-hosted paper](https://li.me.jhu.edu/wp-content/uploads/Alon_2009.pdf) | Scientific interest and feasibility as distinct dimensions of problem choice |
| Pautasso, [Ten Simple Rules for Writing a Literature Review](https://doi.org/10.1371/journal.pcbi.1003149) (2013) | Search records, reading notes, synthesis and updating the literature |
| [Pen before pipette](https://www.nature.com/articles/nmeth.4460) (2017) | Motivation for reducing arbitrary experimental choices; detailed design guidance comes from the sources below |
| Wagner & Kleiner, [How thoughtful experimental design can empower biologists in the omics era](https://pmc.ncbi.nlm.nih.gov/articles/PMC12328601/) (2025) | Rehearse the data structure and intended analysis while planning the experiment |
| NC3Rs, [Experimental Design Assistant](https://nc3rs.org.uk/our-portfolio/experimental-design-assistant-eda) | Animal-experiment diagrams, allocation, blinding and sample-size support |
| Wilson et al., [Good enough practices in scientific computing](https://doi.org/10.1371/journal.pcbi.1005510) (2017) | Raw data, identifiers, project overview, to-do list and organized results |
| NIH OIR, [Intramural Electronic Lab Notebook Policy](https://oir.nih.gov/sourcebook/intramural-program-oversight/electronic-lab-notebooks/intramural-electronic-lab-notebook-policy) | Traceable experimental records; policy obligations apply to NIH intramural work |
| Modi, [Achieve your research goals: a project management toolkit for graduate studies](https://pubmed.ncbi.nlm.nih.gov/39271398/) (2024) | Goals, priorities, decisions and uncertainty in timelines |

## Literature and knowledge tools

Zotero owns bibliographic records and attachments; collections can share the same
item. See [collections and tags](https://www.zotero.org/support/collections_and_tags),
[attachments](https://www.zotero.org/support/attaching_files) and
[Web API v3](https://www.zotero.org/support/dev/web_api/v3/basics).
Obsidian can hold the linked cross-paper synthesis and project decisions in
local notes; see [Properties](https://obsidian.md/help/properties) and
[Bases](https://obsidian.md/help/bases).
Use the user's existing organization and available connectors. Tool documentation
describes capabilities; inspect the actual installation before connecting it.
