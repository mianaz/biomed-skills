# Section responsibilities

| Section | Reader's question | Keep here |
|---|---|---|
| Results | What did we learn from this comparison? | Key design context, comparator, observed direction and magnitude, and the scientific judgment supported by that experiment |
| Discussion | How does this change our understanding? | Synthesis, mechanisms, specific comparisons with prior work, biological consequences and productive open questions |
| Methods | What was done and how was it analyzed? | Actual design, procedures, normalization, analysis units, parameters and statistical comparisons |
| Figure legend | How do I read and assess these panels? | Panel identities, groups, essential conditions, visual encodings, units, n, summaries, error bars and statistical keys |

Read the detailed guidance for the section being written or edited:
[Results](../paper-writing/references/results.md),
[Discussion](../paper-writing/references/discussion.md),
[Methods](../paper-writing/references/methods.md), or
[figure legends](../paper-writing/references/figures-and-legends.md).
Read only the sections needed for the task. Language-only polishing preserves
existing claims and sources; new mechanisms or literature synthesis require
substantive drafting or revision within the user's request.

When revising related sections, reconcile group names, treatments, time points,
normalization denominator/reference, sample units, n, tests and comparison pairs
against the same source. Preserve numbers and directions. Relocate content only
within the authorized edit scope; for a local edit, report a needed relocation
briefly rather than silently rewriting unavailable sections.
