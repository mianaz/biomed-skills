# Manuscript and source-version consistency

Use the designated manuscript with its matching figures, source tables and
analysis version. For a full revision, reconcile consequential numbers and terms
across the title, abstract, Results, legends and supplement.

For features reused across analyses or sections, apply
[analysis consistency](analysis-consistency.md): reconcile the gene set, scoring
algorithm, input transformation, scaling reference and thresholds against the same
feature record. Keep named adaptations and sensitivity analyses identifiable in
both main and supplemental material.

Check group names, treatments, time points, normalization denominator/reference,
independent sample units, n, tests and comparison pairs against the owning source.
Preserve values and directions. If versions disagree, locate both statements and
resolve the difference against the designated source; a newer timestamp alone
does not settle the scientific choice.

Leave unresolved choices visible for the author while completing unaffected edits.
Relocate content within the requested scope and check the destination and reference.
For a local edit whose needed counterpart is unavailable, report the specific
dependent change instead of inventing that counterpart.
