# Biomedical shared references

This directory is a support package shipped with the suite. It has no independent
skill entry point. Keep it beside the installed skill directories.

Read the exact files linked by the active task:

- `writing-principles.md` provides maintained author guidance for biomedical prose.
- `argument-bridges.md` connects examples, explanatory properties and judgments.
- `scientific-semantics.md` checks measured objects and scientific propositions.
- `revision-fidelity.md` governs edit scope, meaning and manuscript versions.
- The other files supply conditional guidance for evidence interpretation, main/supplement placement, paragraph structure, terminology and biomedical examples.
