# Biomedical shared references

This is a support directory, with no independent skill trigger. Keep it beside
its consumers. Each skill loads [core principles](core-principles.md); the remaining
files are conditional references, not a checklist to load for every task.

| Decision or task | Read |
|---|---|
| Biomedical prose | [Writing principles](writing-principles.md) |
| Figure artwork or assembly | [Visual standards](visual-standards.md) |
| Reused features or conflicting analyses | [Analysis consistency](analysis-consistency.md) |
| Selecting, computing or auditing signatures | [Gene-set records](gene-set-records.md) |
| Editing developed prose | [Revision fidelity](revision-fidelity.md) |
| Cross-section values, features or source versions | [Manuscript consistency](manuscript-consistency.md) |
| Claim support or biological interpretation | [Evidence](evidence-and-interpretation.md), [scientific semantics](scientific-semantics.md) |
| Paragraph flow, reasoning or section placement | [Paragraph revision](paragraphs-and-revision.md), [argument bridges](argument-bridges.md), [section responsibilities](section-responsibilities.md) |
| Main/supplement placement | [Result placement](main-text-and-supplement.md) |
| Terms, notation or citations | [Terminology](terminology-and-citations.md) |
| Complete manuscript document export | [Manuscript formatting](manuscript-format.md) |
| Independent feedback requested by the active entry | [Logic review](logic-review.md); the writing entry owns the trigger |
| Existing final text or visual review | [Reader read-back](reader-feedback.md) |
| Requested follow-up experiments | [Next experiment](next-experiment.md) |
| Research ideas, experiment planning or ongoing project work | [Research practice](research-principles.md) |
| Delivering results within a research project | [Project dashboard](project-dashboard.md) |
| Statistical reasoning or interpretation | Relevant sections of [statistical principles](statistical-principles.md) |
| Statistical execution or result verification | Relevant sections of [analysis decisions](statistical-analysis.md) |
| A concrete writing illustration is useful | [Biomedical examples](biomedical-examples.md), [sentence examples](sentence-focus-examples.md) |
| Source rationale or provenance is requested | [Statistical sources](statistical-sources.md), [visualization sources](visualization-sources.md), [research sources](research-sources.md) |

Each common rule has one owning reference. Consumer skills specify when it applies
and own task-specific procedures, examples and deliverables. Keep implementation
details behind those conditional routes.
