## Additional sources and implementation scope

- Hoenig & Heisey (2001), *The Abuse of Power*, sections 2.1, 3 and 4:
  [DOI](https://doi.org/10.1198/000313001300339897). Supports prospective planning
  and effect/interval interpretation of completed studies.
- *How thoughtful experimental design can empower biologists in the omics era*,
  Box 1: [Nature Communications](https://www.nature.com/articles/s41467-025-62616-x).
  Supports rehearsal of the proposed data and analysis.
- Official R documentation for `wilcox.test`, `survdiff`, `cox.zph` and competing
  risks defines the relevant assumptions.
- AIPW and hmmlearn official documentation defines estimator and decoding assumptions.

The statistical method modules distinguish source concepts from suite implementation
checks. Advanced imputation, causal designs, equivalence/noninferiority, ordinal or
count models and specialist algorithms require additional primary documentation
when used. This catalogue is not loaded for every statistical task.
