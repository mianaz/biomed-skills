# Gene sets and signatures

Use when a task depends on a gene set's identity or computation. Unless the user
requests custom construction, first seek a published, validated set appropriate
to the biological setting. Preserve its source definition and distinguish any
adaptation. Follow user preferences or a valid established scoring method; select
an undecided method for the data and question.

Reuse one membership and computation record across analysis, figures and Methods.
Retain:

- Set name/ID, species, source publication or database release/version, complete
  original and used gene lists, directions/weights, mapped IDs and omissions or
  additions with their reasons.
- Actual scoring/enrichment method, software/function/version, input layer and
  normalization, analysis unit and key parameters. Distinguish score calculation,
  display scaling and group averaging.
- Scaling axis, reference and aggregation for standardized scores; ranking
  statistic, contrast and tested universe for enrichment analyses.

Link the record from the relevant panel, section or evidence node. Use an existing
table, or `gene-sets.tsv` when a reusable export is needed. For supplied results,
preserve the actual computation and identify unavailable fields. A documentation
task fills records from sources; new computation follows the requested analysis scope.
