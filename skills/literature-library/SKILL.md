# Literature Library

Read [shared principles](../biomed-shared/core-principles.md).

Make the literature useful for a research decision. Start with the question,
the user's existing library and the intended depth of coverage. Reuse Zotero
collections, citation keys, local PDFs and knowledge notes where available.
Read [research principles](../biomed-shared/research-principles.md).
If a library connection fails, use the project's reference export and report the
lookup as unavailable; do not treat it as evidence that the papers are absent.

## Find and organize

- Establish the biological system, phenomenon, decision and scope. For a new
  field, map its central questions, landmark findings, competing models and
  useful methods before building a long reading queue.
- When finding or expanding the literature, search primary papers using concept synonyms, influential seed papers,
  backward references and forward citations. Include the closest competing
  work, relevant exceptions and recent developments. Record the search date,
  databases, useful queries and coverage. A focused library needs a bounded
  search; a systematic review needs its own explicit eligibility and search plan.
- Resolve DOI/PMID, title, authors, version and publication status. Merge duplicate
  entries using identifiers plus metadata; link preprint and published versions.
  Preserve existing annotations and distinguish corrections or retractions.
- Keep bibliographic metadata and attachments in the reference manager. Put
  cross-paper ideas and project implications in the existing wiki. Link them by
  stable item URI or citation key. A paper can belong to several collections
  without duplicating its PDF.

## Turn reading into understanding

Use a small reading queue ordered by what could change the current decision:
orientation, close reading, method reuse or reserve. Useful per-paper fields are
identifier/link, question, model/system, main result, exact figure/page locator,
reading coverage and relevance to the project. Add fields only when needed.
Use `paper-distill` for detailed reading and `paper-evidence-map` when a complex
argument needs an editable map.

Synthesize across papers around a question or competing explanation. Explain
where findings converge, where conditions differ and which comparison could
resolve a productive disagreement. Distinguish independent studies from several
analyses of the same cohort. Finish with what the researcher now understands and
the most useful next read, analysis or idea. Use `research-ideation` when asked
to develop new questions from that synthesis.

For an update, inspect new or changed sources and revise the affected synthesis.
Promote a paper into a project task when it changes a question, method, result
interpretation or practical decision. Keep other useful papers in the library.
Create recurring searches only when the user asks for a schedule.

## Deliver

Deliver the requested library, thematic map, reading queue or synthesis with its
source record. Create an import file when it is part of the requested library work.
Report whether
full text, supplements, abstract or metadata were read. Generating an import file
does not establish that it has been imported into Zotero or a wiki.
For a project deliverable, link the library and synthesis from its
[root dashboard](../biomed-shared/project-dashboard.md).

Read [source guidance](../biomed-shared/research-sources.md) only for the underlying
practice or current tool documentation.
