# Paper Writing

## Prepare

Read [writing principles](../biomed-shared/writing-principles.md) before drafting.
Read the supplied evidence and reuse an existing framing brief, claim IDs and
terminology. A brief is optional: develop the argument needed for the requested
text directly from the evidence. Preserve the user's scope and previous decisions.

Use [evidence and interpretation](../biomed-shared/evidence-and-interpretation.md)
when judging claims or proposed mechanisms, and
[terminology and citations](../biomed-shared/terminology-and-citations.md) when
writing from sources or applying journal requirements.

## 1. Establish the passage's scientific purpose

Identify the question, principal finding and interpretation the reader should
understand. For a whole manuscript, identify the central claim and the questions
answered by its sections. Finish this step when the requested prose has a clear
scientific purpose and its consequential statements have source support.
If the user expressly requests a choice among competing scientific stories,
complete that task with `paper-framing` and reuse its recommendation.

## 2. Read the relevant section guidance

Load only the requested sections:

| Requested text | Guidance |
|---|---|
| Title | [Title](references/title.md) |
| Abstract | [Abstract](references/abstract.md) |
| Introduction | [Introduction](references/introduction.md) |
| Results | [Results](references/results.md) |
| Discussion | [Discussion](references/discussion.md) |
| Methods in an existing manuscript | [Methods](references/methods.md) |
| Figure legends | [Figures and legends](references/figures-and-legends.md) |
| Significance paragraph or cover letter | [Cover letter](references/cover-letter.md) |

Read [result placement](../biomed-shared/main-text-and-supplement.md) for Results,
whole-manuscript compression or content relocation. Read
[paragraph development](../biomed-shared/paragraphs-and-revision.md) when building
or restructuring paragraphs. Completion is the guidance needed for this request.

## 3. Draft the requested text

Build the prose around the discoveries and their scientific meaning. Develop
local interpretation in Results and synthesis across findings in Discussion.
Keep numerical evidence and source pointers attached to the relevant claims.
Write Chinese source notes in natural biomedical English when that is requested.

For Methods derived from a protocol and execution records, use
`protocol-to-methods` to establish what was performed. For a submission package,
`submission-check` owns the journal requirements and file checks. A cover-letter
writing request can be completed here using verified facts and requirements.

Complete this step with the requested prose. Reuse available data under deadline
constraints and place explicit placeholders only where missing facts require them.
An outline is the deliverable only when the user asks for an outline.

## 4. Revise and deliver

Check scientific interest and biological significance alongside factual accuracy.
Check numbers, terminology, citations and figure correspondence in the affected
text. Make language improvements within this task. `paper-polishing` serves an
independent request to improve existing prose; it is not a mandatory final stage.

Return the draft and brief notes for consequential choices or unresolved facts.
For a manuscript, verify alignment of the title, abstract, headings and figures.
Completion is usable text at the scope requested by the user.
