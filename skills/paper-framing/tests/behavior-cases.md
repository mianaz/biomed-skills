# Behavior review cases

These cases specify expected editorial behavior. They require a model response
and human review; the structural package check does not execute or score them.
Use fictional supplied evidence, and preserve that designation in any examples.

| Case | Request and input | Expected behavior |
|---|---|---|
| Undersold discovery | Persistent state and altered later response; author calls the work “merely descriptive” | Develop the biological insight; state observations directly; propose a memory model with a useful prediction |
| Unresolved mechanism | Perturbation affects occupancy and expression; recruitment order unknown | Explain the regulatory relationship; develop a proposed model; keep direct interaction claims aligned with evidence |
| Material contradiction | Main perturbation supports a claim but its decisive control contradicts specificity | Keep the contradictory result visible; revise the explanation while developing the remaining scientific value |
| Context dependence | Effects differ between measured cell states | Examine whether selectivity reveals a biological dependency; preserve estimates and uncertainty |
| Existing data only | Deadline prevents new experiments | Complete a coherent framing and requested draft from available evidence; distinguish optional future tests |
| Local revision | User requests one Discussion paragraph | Deliver that paragraph; preserve scientific ambition and established terminology; avoid imposing a full study inventory |
| Proposed mechanism | Authors propose an explanation not directly tested | Articulate the full proposal and its reasoning, labeled at its actual status; derive a discriminating prediction |
| Nature-style prose | Journal unspecified | Improve scientific argument and accessibility; verify official rules only when actual journal requirements are requested |
| Missing source | Only abstract and two panels are accessible | Assess available material; disclose the access gap once; avoid claiming a full manuscript review |
| Skill isolation | Only the paper-framing folder is installed | Complete framing and drafting using its own SKILL.md and bundled resources |
| Null finding | Confidence interval includes meaningful effects | Preserve the uncertainty; avoid treating lack of significance as equivalence; articulate only supported interpretation |
| Figure sequence | Five analyses repeat one conclusion and two establish new inferences | Group repetition and foreground the analyses that advance the biological argument |
