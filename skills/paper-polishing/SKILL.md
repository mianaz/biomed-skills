# Paper Polishing

## Prepare

Read [writing principles](../biomed-shared/writing-principles.md) before editing.
Use the supplied passage, its nearby context and established terminology. Identify
whether the user requests polishing, translation or compression, and retain the
agreed language, audience and edit scope.
Read [revision fidelity](../biomed-shared/revision-fidelity.md) to apply the
default minimal edit and compare the original and revision. It includes the
local growth target, meaningful negation and manuscript-version checks.

Use [terminology and citations](../biomed-shared/terminology-and-citations.md) for
scientific terms, quantities and references. Read
[paragraph development](../biomed-shared/paragraphs-and-revision.md) when sentence
relationships or paragraph organization need repair. For Results compression or
moving material, read [result placement](../biomed-shared/main-text-and-supplement.md).
Read [argument bridges](../biomed-shared/argument-bridges.md) for missing premises,
detached cause-and-effect lists or summary terms without concrete support.

## 1. Identify the intended message

State internally the finding and interpretation the passage communicates. Identify
phrasing that obscures the scientific value and information that must be retained.
Complete this step when the edit can preserve both the factual meaning and the
idea's ambition. Rebuilding a study's central story belongs to `paper-framing`;
drafting a new section or substantially rebuilding its argument belongs to
`paper-writing`. Translation of developed prose stays here; constructing an
English draft from fragmentary notes belongs to `paper-writing`.

## 2. Improve the prose

Make subjects, verbs and sentence relationships clear. Replace empty praise with
the scientific value already supported in the passage. Remove stacked hedges,
repetition and habitual apologies while preserving meaningful uncertainty.
Compress routine wording and retain the reasoning needed to understand the
finding. Translate an existing passage faithfully into the requested language.

For an undersold result or an unresolved mechanism, consult the relevant
[biomedical example](../biomed-shared/biomedical-examples.md). Make the intended
proposal clear at its stated evidential status. New claims or mechanisms require
an explicit substantive writing request and supporting material.

Complete this step with revised text. Where the source contains a consequential
scientific ambiguity, use [evidence and interpretation](../biomed-shared/evidence-and-interpretation.md)
to explain the issue and revise only as far as the available facts support.

## 3. Check and deliver

Compare original and revision proposition by proposition using revision fidelity
and [scientific semantics](../biomed-shared/scientific-semantics.md). Check the
measured object as well as numbers, conditions and inference. Keep correct prose
unchanged where useful. A language edit does not certify unread cited sources;
`citation-audit` handles a requested claim-to-source audit.
Check that clearer language has preserved the positive scientific value.

Apply [logic review](../biomed-shared/logic-review.md) when its substantive drafting
or structural-revision trigger fits this task; resolve material findings before
delivery.

Return the revised passage, with brief notes for changes that affect meaning or
need an author decision. For local editing, completion is that passage and its
applicable checks. A full study inventory is needed only for a request at that scope.
