# Paper Polishing

Read [shared principles](../biomed-shared/core-principles.md).

## Set the edit scope

Read [writing principles](../biomed-shared/writing-principles.md) and
[revision fidelity](../biomed-shared/revision-fidelity.md). Use the passage, nearby
context and established terminology. Identify the intended finding and meaning;
retain the requested language, audience and scope. Local polishing defaults to
minimal edits. Reuse guidance already read from this version.

## Edit using the relevant references

Make subjects, verbs and scientific relationships clear. Preserve effective author
voice and the idea's ambition. Compress routine wording while retaining needed
reasoning; translate developed prose faithfully. Use only the references needed
for the edit:

| Issue in the passage | Reference |
|---|---|
| Existing title or abstract | [Title](../paper-writing/references/title.md) or [abstract](../paper-writing/references/abstract.md), as applicable |
| Figure legend | [Figures and legends](../paper-writing/references/figures-and-legends.md) |
| Section function or content placement | [Section responsibilities](../biomed-shared/section-responsibilities.md) |
| Terms, quantities, citations or figure references | [Terminology and citations](../biomed-shared/terminology-and-citations.md) |
| Structure, focus, voice, rhythm or repetition | [Paragraph revision](../biomed-shared/paragraphs-and-revision.md) |
| Missing premise, detached examples or unearned synthesis | [Argument bridges](../biomed-shared/argument-bridges.md) |
| Results compression or moving content | [Result placement](../biomed-shared/main-text-and-supplement.md) |
| Assay wording, negation, measured object or inferential ambiguity | [Scientific semantics](../biomed-shared/scientific-semantics.md) |
| Uncertain claim support or a proposed mechanism | [Evidence and interpretation](../biomed-shared/evidence-and-interpretation.md) |
| Undersold discovery needing an illustration | [Biomedical examples](../biomed-shared/biomedical-examples.md) |
| Existing response to reviewers | [Reviewer response](../paper-writing/references/reviewer-response.md) |

## Check and deliver

Compare original and revision using revision fidelity. Retain correct prose where
useful and keep the positive scientific value clear. Apply the writing principles'
guidance at the actual edit scope. Language editing, faithful translation and
reordering that preserves the reasoning chain use direct checks at any length.
For explicitly requested independent feedback, use
[logic review](../biomed-shared/logic-review.md). Return the revised passage.

Developing new claims or mechanisms needs a substantive writing request and
supporting evidence. `paper-writing` owns new sections and rebuilding the main
question or reasoning chain;
`paper-framing` owns a new central story. A requested systematic verification of
cited claims belongs to `citation-audit`; preserve references and flag specific
issues encountered during ordinary polishing.
