# GraphPad Prism

Read [shared principles](../biomed-shared/core-principles.md).
Select the route from the requested artifact:

| Request | Read and deliver |
|---|---|
| Editable data tables only | Use the [Prism table writer](../scientific-plotting/references/graphpad-prism.md); verify values, IDs, blanks and table structure, then deliver the data-only PZFX and direct CSV. |
| Native graph or project | Use the native-project procedure below and the same [Prism reference](../scientific-plotting/references/graphpad-prism.md). |

For a new chart without a supplied template, select its encoding from
[chart design](../scientific-plotting/references/visual-design.md#match-the-reading-task)
and inspect a suitable native template. Consult the [template catalog](references/template_catalog.md)
when locating one; availability depends on the current project or supplied library.
For a rendered graph, apply [visual standards](../biomed-shared/visual-standards.md).
For new or revised inference, read the relevant
[analysis decisions](../biomed-shared/statistical-analysis.md) and
[statistical display](../scientific-plotting/references/statistics.md).

## Native project procedure

1. Identify the table type, independent units, pairing, replicate subcolumns,
   missing values and existing analyses. Preserve the original; edit a copy.
2. Populate the native table using Prism or a verified format-specific editor.
   Preserve graph/table links. After data changes, check analysis settings, rerun
   linked analyses and reconcile annotations. Appearance-only edits retain valid
   results. Follow the Prism reference's format-specific preservation rules.
3. Inspect the saved project in Prism and the requested graph exports. Use
   [figure verification](../scientific-plotting/references/figure-verification.md)
   for exported graphs and [delivery](../scientific-plotting/references/figure-delivery.md)
   for their source records. Deliver the editable native project.

A data-only request finishes after table validation. If native graph work needs
unavailable Prism access, deliver the supported table and identify native rendering
as pending. Add an R figure when the requested output includes a usable figure or
an alternative rendering. Report which software actually ran the analysis.
