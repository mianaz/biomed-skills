使用方法

选择对象，直接编辑

  1. 用新助手导出 R/ggplot2 或 matplotlib 项目，在此打开 project.json。
  2. 画布点击选择单个对象。左侧列表可选整条坐标轴、数据系列、文字或图形；Alt + 点击也能选对象组。拖动或用方向键移动。
  3. 右侧调整字体、字号、旋转、文字首部／中部／尾部对齐、颜色、线宽、点大小和条形宽度。左侧可切换 Theme 与调色板。
  4. 上方添加文本框、标题、副标题、图例和图形。统计可用项目观测值或导入 CSV，显示 P 值或星号。
  5. 保存完整项目继续编辑；下载 tuner.json 和重放代码，在原绘图脚本中重跑。

R 复合图请传入命名的独立 ggplot 列表。Theme 是可重放的矢量显示样式。坐标轴标签与几何可编辑；数据重算与坐标尺度定义仍由原绘图代码生成。

项目结构变化后，请核对元素映射。PDF 转换可能将文字转为路径。图中星号：* P<0.05，** P<0.01，*** P<0.001，**** P<0.0001。

交互参考：mpltweak · Tavotto。
