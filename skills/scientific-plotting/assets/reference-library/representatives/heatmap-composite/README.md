# heatmap-composite demonstration

Synthetic demonstration data, created for a visual representative where the registered group has no stored preview. The original variants remain linked in the full database.

Run `Rscript --vanilla template.R` in this folder. Edit input.csv to use supplied values. The heatmap also reads tracks.csv. The incidence template requires time, status (0 censored; 1 and 2 competing events), and group.

Arial 11 pt. PDF, PNG, input tables and native R plot objects are supplied. Render and layout checked; replacement-data testing is pending.
