# Personal plot libraries

Use the user's selected original figure, actual plotting code and input data as
an optional local reference. Keep private project code, figures and selection
records outside the distributed skill. Reuse the existing library location.

Read the original export and code together. Identify its data transformation,
statistical comparison, required packages and version before adapting it. Preserve
meaningful arrows, overlays, labels, facets and native plotting engines. Change
data bindings explicitly; save the new code, direct data and editable object.
Compare the rendered adaptation with the selected original at the requested size.

Use the [template database](template-database.md) with `--personal-dir` to browse
an existing private library. Source discovery, replay of an original, and testing
with new data are separate states. Keep unresolved originals visible at their
actual status. Merge variants only when their code and plotting logic agree.
