# Reproducible figure handoff

For a reported data figure, retain the direct plotting table, runnable source,
plot object or native project, and any supplied or computed statistical results.
Link the output to its inputs and analysis settings in the project record. Keep
excluded observations identifiable in source data and state consequential
exclusions in the caption.

Use [scientific-plotting](../../scientific-plotting/SKILL.md) for export formats,
viewing size, typography, statistical display and rendered verification. Reuse
its export helpers. Keep titled/clean versions or separate legend files when the
project or assembly requires them; a figure handoff does not mandate extra versions
for every task. Preserve existing required versions when revising an analysis.

Appearance-only edits reuse valid data and statistics. For descriptive figures,
retain the displayed quantities and summary definitions without adding a test.
