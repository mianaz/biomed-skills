# TGFβ pathway icon QC

These 8 editable teaching vectors use the shared 160 × 160 canvas and v0.3 style. Their paths are original and covered by the package MIT license. No BioRender artwork or vectors were copied.

## Visual design reference

[BioRender TGFβ signaling template](https://www.biorender.com/template/tgf-beta-signaling-pathway) is the sole visual-design reference for this set. Its public rendered preview was inspected for silhouette and pathway-layout conventions. It is proprietary reference material; the delivered SVG geometry is original.

## Scientific QC references

These papers support pathway and domain content. They are kept separate from the visual-design reference.

| Paper | Inspection and scientific scope |
|---|---|
| [Derynck & Budi, SMAD signaling review, Fig. 4](https://pmc.ncbi.nlm.nih.gov/articles/PMC6800142/) | Figure visually inspected for SMAD domain organization and pathway relationships. |
| [TGFβ signaling and SMAD domain review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4485443/) | Domain descriptions consulted for receptor, R-SMAD, co-SMAD and inhibitory-SMAD context; source coordinates were not traced. |

## Feature and render checks

| Icon | Scientific feature checked |
|---|---|
| TGFβ ligand dimer | Paired cystine-knot subunits and central interchain interface |
| TGFβRI / ALK5 | Ectodomain, single-pass helix, GS regulatory segment and bilobal kinase |
| TGFβRII | Ligand-binding ectodomain, single-pass helix and bilobal kinase |
| SMAD2 | MH1, exon-3 insertion, connected linker, MH2 and terminal SSXS motif |
| SMAD3 | MH1 DNA-binding hairpin, connected linker, MH2 and terminal SSXS motif |
| SMAD4 | MH1 hairpin, linker/activation segment and MH2; no R-SMAD SSXS tail |
| SMAD7 | Connected PPXY-bearing N-terminal chain and MH2 domain |
| SMURF2 | C2–WW1–WW2–HECT domain order and catalytic-cysteine marker |

Prototype CairoSVG renders at 64, 96 and 160 px were visually checked. Validation confirms 8 manifest entries; matching named SVG parts, including membrane context; allowed palette; 160 × 160 viewBoxes; unit anchor normals; anchors on rendered artwork; no embedded text, images or filters; and alpha bounds inside the canvas with margin.
