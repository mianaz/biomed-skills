# IFNγ–JAK–STAT icon

Use the editable SVGs with their named parts, state labels and contact anchors.
Geometry describes schematic features; retain the manifest scope when adapting
the artwork to a specific biological claim.

| Icon | Use and scope |
|---|---|
| IFNγ dimer | IFNγ homodimer schematic; full receptor complex stoichiometry is 2 IFNγ:2 IFNGR1:2 IFNGR2. Contact markers are schematic, not atomic interfaces. |
| IFNGR1 | One receptor chain only. The complete IFNγ signaling complex contains 2 IFNγ, 2 IFNGR1 and 2 IFNGR2 chains. |
| IFNGR2 | One receptor chain only. The complete IFNγ signaling complex contains 2 IFNγ, 2 IFNGR1 and 2 IFNGR2 chains. |
| JAK1 | Schematic JAK domain architecture; kinase activation state is not encoded. |
| JAK2 | Schematic JAK domain architecture; kinase activation state is not encoded. |
| STAT1 | Continuous STAT monomer schematic with exposed SH2, pY-tail, DNA-binding, and importin-alpha5 surfaces; reciprocal pY–SH2 dimer contact is summarized by dimer-interface. |
| STAT3 | Continuous STAT monomer schematic with exposed SH2, pY-tail, DNA-binding, and importin-alpha5 surfaces; reciprocal pY–SH2 dimer contact is summarized by dimer-interface. |
| STAT5 | Continuous STAT monomer schematic with exposed SH2, pY-tail, DNA-binding, and importin-alpha5 surfaces; reciprocal pY–SH2 dimer contact is summarized by dimer-interface. |
| Importin α5 | Importin-α5 cartoon; phospho-STAT1 recognizes a nonclassical import surface. |
| Importin β1 | Generic importin-β1 transport schematic; no transport cycle state is implied. |
| GAS DNA | Double-stranded GAS response element schematic; the central sequence is highlighted, and the opposing strands cross in this 2D helix convention. |
| RNA polymerase II | Compact polymerase clamp with a DNA cleft. A short embedded DNA helix is contextual art and can be omitted when the scene supplies promoter DNA. |
| Nuclear pore cutaway | Side-view nuclear pore cutaway with open 44-unit channel; membrane stubs are context and midplane anchors mark the source double-envelope coordinates. |
