The model behind the picture

These are deterministic binary teaching models. Every variable is either 0 (off) or 1 (on). The slider sets p, the fraction with U = 1. All percentages are calculated expectations, not study results. Arrows denote causal assumptions within each toy model.

  • Model A: X = U; Y = X.
  • Model B: X = U; Y = U.
  • Observation in either model: P(Y = 1) = p.
  • Intervention replaces the equation for X with X = 0. It leaves U unchanged. Then P(Y = 1) = 0 in A and P(Y = 1) = p in B.

For 0 < p < 1, X and Y are perfectly correlated during observation. At p = 0 or p = 1, correlation is undefined because there is no variation. At p = 0, this intervention cannot distinguish the two models.

Connect the lesson to an experiment

This ideal intervention changes X alone. A real perturbation may have incomplete action, off-target effects, feedback or additional routes to Y. Controls and context determine which explanation an experiment can support. The diagram does not establish a mechanism in a biological system.
