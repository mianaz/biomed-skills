# Project scope

This repository owns general biomedical skills: scientific plotting, GraphPad
Prism, paper distillation/evidence maps, protocols and Labmate integration,
Methods writing, submission preparation and shared reproducibility.

Single-cell analysis lives in https://github.com/mianaz/sc-skills and is maintained
separately. Keep domain-specific single-cell workflows there; keep shared skills
here. Do not add a second copy of a shared skill to sc-skills.

Prefer small, direct changes. Use R/cowplot and Arial for scientific figures,
with all text >10 pt at final viewing size. Preserve direct plotting data and
editable source. Run the relevant existing script checks after code changes.
